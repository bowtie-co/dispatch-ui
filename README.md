# reach-react-ui

Helios Reach


### Docker Setup
Initial setup (only run once)

```bash
bin/setup
```

### Docker Rebuild
Rebuild on change (required with package.* changes)

```bash
bin/rebuild
```

### Docker Start
Run local dockerized service(s)

```bash
bin/start
```

### Docker Linting

```bash
# Lint only
bin/lint
# Lint + auto-fix
bin/lint-fix
```

### Docker Testing

```bash
bin/test
```


### Local Setup

```bash
npm install
```

### Development

```bash
npm run start
```

### Linting

```bash
# Lint only
npm run lint
# Lint + auto-fix
npm run lint:fix
```

### Testing

```bash
npm test
```
